CREATIVE DIRECTION GALLERY — photos (with a title on open)
=========================================================

Drop your images in THIS folder (assets/creative/). Any name is fine
(spaces ok). Number them to set the order: 01-..., 02-...

Each project shows its TITLE only when opened (one line at the bottom),
just like the Design gallery. If a project has several images it can be a
carousel. After uploading, send me for each project:
  • the TITLE, and
  • which files belong to it (in order).
