DESIGN GALLERY IMAGES
=====================

Drop your Design images in THIS folder (assets/design/).

- Any name is fine (spaces are ok too). Keep them in the order you want
  them to appear by prefixing with a number, e.g.:
    01-poster-artist.jpg
    02-cover-single.jpg
    03-brand-identity.jpg
- Square or portrait images look best in this grid.

After you upload, tell me (or it's fine to leave it to me):
  • the TITLE for each image (shown over it), and
  • a short ROLE / description line (e.g. "Poster · Graphic Design").
If you don't send titles, I'll use the file name as the title and you can
refine the wording later.
